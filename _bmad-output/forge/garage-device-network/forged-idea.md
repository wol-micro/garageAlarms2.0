# Forged idea: децентрализованная сеть garageAlarms

**Статус:** HARDENED · 2026-09-29

## Решения
- Децентрализация, без хаба. Модель AP: eventual consistency; дубль допустим, **потеря — нет**.
- Два класса узлов:
  - **Логические (2..N)** — ESP32 + FRAM: реплика очереди, конфиг/правила, веб, Telegram. Один LEADER, остальные FOLLOWER.
  - **Коллекторы** — только датчики и пересылка; маленький постоянный буфер до e2e ACK; не голосуют.
- Лидер нужен только для подавления дублей, не для истины. Мягкий лидер = наименьший живой ID по gossip-членству.
- **Арбитр — Telegram:** 409 Conflict на `getUpdates` выдаёт второго лидера даже при разрыве внутренней сети; узел с большим ID уступает.
- Статусы: LEADER / FOLLOWER (досылает, если нет отметки «доставлено» за T) / ISOLATED (шлёт тревоги сам, «аварийный режим»).
- Доставка at-least-once: коллектор шлёт всем логическим; ID = узел+счётчик; дедуп на приёме.
- Слои: L0 Zigbee+WiFi · L1 mesh · L2 надёжная доставка · L3 членство/живость (тревога на молчание) · L4 репликация (LWW per-rule) · L5 правила и шлюзы. Сквозные: HMAC, время, OTA.
- Постоянная память — FRAM. Провода датчиков — оконечные резисторы + АЦП (норма/тревога/обрыв/КЗ).
- В чате: подпись узла, `/status` с лидером, `/leader <узел>`.

## Отвергнуто
- Zigbee на ESP32-S3 — нет радио 802.15.4 (нужен H2/C6 или модуль).
- SSD/SD как память — FRAM проще и долговечнее.
- Raft/строгий кворум, 3-й обязательный узел, голосующие коллекторы — не нужны при AP-модели.
- Готовые Zigbee-датчики — у пользователя свои проводные.
- Второй внешний канал (LTE/SMS, сирена) — отложен, Telegram работает.

## Открытые трещины
- Long polling (`timeout≈20с`) обязателен для арбитража — сейчас `timeout:0` (`AsyncTelegram2.cpp:172`), правка вендорной библиотеки.
- `offset` Telegram реплицировать; команды идемпотентны (иначе повтор `/reboot`).
- LWW теряет конкурентную правку одного правила — показывать конфликт в вебе.
- Telegram — единственный внешний канал.
- Текущий NVS 20 КБ изнашивается очередью в худшем случае — уходит с переходом на FRAM.
