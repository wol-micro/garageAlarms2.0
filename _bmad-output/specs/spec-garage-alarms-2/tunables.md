# Стартовые значения констант

Живут в `components/ga_config/include/ga_config.h` (AD-25). Уточняются на прототипе. «Мягкая» — может переопределяться мягким конфигом.

| Константа | Старт | Мягкая |
| --- | --- | --- |
| T — ведомый страхует критичное | 45 с | нет |
| N — uplink потерян | 60 с неудач | нет |
| M — uplink восстановлен | 120 с успеха | нет |
| Возврат лидерства приоритетному узлу | 15 мин стабильного uplink | нет |
| Heartbeat логического / коллектора | 10 с / 30 с | нет |
| `stale` узла или канала | 3 пропущенных heartbeat | нет |
| Аренда Telegram: продление / срок | 5 мин / 15 мин | нет |
| Пауза `YIELDED` без аренды | 30 с × (1 + ранг) | нет |
| Повтор длящейся тревоги дыма | 15 мин | да |
| Залипший PIR → неисправность | 2 ч | да |
| Выключение критичного правила: по умолчанию / максимум | 2 ч / 12 ч | по умолчанию — да, максимум — нет |
| Уведомление о перезагрузке: неожиданной / плановой | ≤ 1 за 15 мин / ≤ 1 за 6 ч | нет |
| Ежедневный отчёт «жив» | 09:00 местного | да |
| Пауза между отправками в Telegram | 350 мс | нет |
| Pushover emergency: retry / expire | 60 с / 3 ч | да |
| Антидребезг / cooldown / прогрев PIR | по каналу, по умолчанию как в 1.x (200–400 мс / 2–5 мин / 60 с) | да |
| Подтверждение опасной команды в боте | 2 мин | нет |
| Шаг выбора срока выключения тревог | 30 мин | нет |
| Событий на странице в боте | 10 | нет |
| Обновление сводки веба | 5–10 с | нет |
| Вход в веб: попыток / пауза | 5 / 5 мин | нет |
| Пакет ключей нового узла | одноразовый, 30 мин | нет |
| Окно ввода коллектора | 5 мин | нет |
| Статистика владельца | 7 дней | нет |
