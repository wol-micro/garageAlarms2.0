# Стартовые значения констант

Живут в `components/ga_config/include/ga_config.h` (AD-25) под указанными именами. Уточняются на прототипе. «Мягкая» — может переопределяться мягким конфигом.

## Сеть, лидерство, доставка

| Константа | Имя | Старт | Мягкая |
| --- | --- | --- | --- |
| T — ведомый страхует критичное | `GA_CRIT_FOLLOWER_T` | 45 с | нет |
| N — uplink потерян | `GA_UPLINK_LOST` | 60 с неудач | нет |
| M — uplink восстановлен | `GA_UPLINK_RESTORED` | 120 с успеха | нет |
| Возврат лидерства приоритетному узлу | `GA_LEADER_RETURN` | 15 мин стабильного uplink | нет |
| Пауза после старта до лидерства и `getUpdates` | `GA_JOIN_GRACE` | 30 с | нет |
| Heartbeat логического / коллектора | `GA_HB_LOGIC` / `GA_HB_COLLECTOR` | 10 с / 30 с | нет |
| `stale` узла или канала | `GA_STALE_MISSED_HB` | 3 пропущенных heartbeat | нет |
| Аренда Telegram: продление / срок | `GA_LEASE_RENEW` / `GA_LEASE_TTL` | 5 мин / 15 мин | нет |
| Пауза `YIELDED` без аренды | `GA_YIELD_BASE` | 30 с × (1 + ранг) | нет |
| Окно антиповтора `seq` | `GA_SEQ_WINDOW` | 512 | нет |
| Хранимых окон загрузок узла | `GA_DEDUP_BOOTS` | 4 | нет |
| Ожидание ACK всех / порог «глухого» узла | `GA_ACK_ALL_TIMEOUT` / `GA_DEAF_MIN_RETRIES` | 5 мин / 10 повторов | нет |
| Переходный период смены ключа HMAC | `GA_KID_TRANSITION` | 7 сут | нет |
| Максимум одного Zigbee-кадра | `GA_ZB_FRAME_MAX_BYTES` | 80 Б | нет |
