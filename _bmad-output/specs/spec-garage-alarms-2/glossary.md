# Глоссарий

| Термин | Значение |
| --- | --- |
| Логический узел | ESP32-S3 + H2 с FRAM: реплика очереди, конфига и правил, веб, внешние каналы; 2..N в сети |
| Коллектор | ESP32-H2: датчики, выходы и пересылка по Zigbee; исполняет только локальные правила |
| Канал | Единица модели датчика или выхода: `binary`, `numeric`, `counter`, `enum`, `output`; одно устройство даёт N каналов |
| Здоровье канала | `ok`, `fault`, `open` (обрыв), `short` (КЗ), `stale` (молчит) |
| Критичное событие | Событие с `k`=критично (дым, вода, неисправность критичного канала); не глушится mute, дублируется в Pushover |
| `LEADER` | Логический узел, который отправляет наружу и читает команды Telegram |
| `FOLLOWER` | Логический узел с копией очереди; страхует критичное через T |
| `YIELDED` | Узел, уступивший после 409, до истечения чужой аренды или паузы |
| `ISOLATED` | Нет соседей и нет связи наружу: только копит |
| Uplink | Бинарная «здоровая связь наружу» с гистерезисом |
| Аренда | Закреплённое сообщение в чате владельца `lease{node, priority, until}` |
| Единица доставки | `(event_id, recipient, channel)` |
| `delivered` | Реплицируемая отметка доставки единицы |
| `ack` | Реплицируемое подтверждение тревоги человеком |
| Мягкий конфиг (S) | Настройки, меняемые живьём через веб и реплицируемые |
| Манифест | Описание датчиков и драйверов в прошивке (уровень H) |
| Набор правил / режим | Группа правил, включаемая режимом («дома», «уехал», «ночь») |
| Граф зон | Смежность помещений для цепочек и трасс |
| Производное событие | Результат правила; ID `rule_id@window_start` |
| Пометка «с опозданием» | Пометка сообщения, пролежавшего в очереди |
| Выход | Канал `output` на коллекторе: реле `switch` (вкл/выкл) или `buzzer` (импульс, сам выключается) |
| Уровень команды | `protect` > `manual` > `auto`; узел выхода держит по слоту на уровень, действует старший |
| Намерение | `output_intent` — реплицируемое событие ручной команды выхода (веб, бот, MQTT) |
| Локальное правило | Правило «событие своего канала → свой выход», исполняемое самим коллектором без логических узлов |
| MQTT-узел | Логический узел, выбранный по связи с брокером: публикует зеркало и принимает команды MQTT |
| `max_on` | Предельное время включения выхода; узел выключает выход сам |
