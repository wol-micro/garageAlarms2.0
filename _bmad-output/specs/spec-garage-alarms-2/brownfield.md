# Наследие garageAlarms 1.x

Репозиторий `garageAlarms` (Arduino, ESP32-S3, один узел, два входа) остаётся рабочим до ввода новой сети; код не переносится. Переносится поведение:

| Урок 1.x | Где закреплено в 2.0 |
| --- | --- |
| Ничего не ждать без таймаута (бесконечный цикл чтения → watchdog → петля перезагрузок → флуд) | AD-3 |
| `setup()` не ждёт WiFi — сеть как конечный автомат | AD-3 |
| Антидребезг по времени + cooldown, не защёлка | AD-15 |
| Входы подтянуты к неактивному уровню: обрыв = тихо → в 2.0 заменено шлейфами с EOL | AD-15, `sensor-catalog.md` |
| Элемент очереди удаляется только после успеха; очередь переживает перезагрузку | AD-4, AD-8 |
| Переполнение: сначала вытесняется некритичное | AD-8 |
| Длящийся дым — повторное напоминание; длительное движение — неисправность | `rule-templates.md` (шаблоны 1, 3) |
| Уведомление о перезагрузке — владельцу, с причиной сброса, с ограничением частоты | AD-22 |
| Ежедневный heartbeat владельцу | AD-19 |
| Mute не глушит критичное | AD-11 |
| TLS только после синхронизации времени | AD-3 |
| Пометка «с опозданием» | Conventions каркаса |
| Структуры, сохранённые сырыми байтами, ломаются при смене раскладки → в 2.0 CBOR с версией | AD-5, AD-6 |
