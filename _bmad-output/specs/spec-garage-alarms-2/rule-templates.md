# Шаблоны правил

Экземпляр: `{id, type, enabled, params, set, severity, notify, when?, ver}`. Все правила исполняются на каждом логическом узле (AD-16).

| # | Шаблон | Пример |
| --- | --- | --- |
| 1 | Состояние / порог | дым (пока держится — напоминание каждые 15 мин); протечка; t > 45 °C |
| 2 | Скорость изменения | t растёт > 8 °C/мин |
| 3 | Здоровье | канал `stale`/`open`/`short`; узел пропал; движение без перерыва > 2 ч — неисправность (один раз) |
| 4 | Совпадение (И в окне) | вода в гараже и коридоре за 10 мин |
| 5 | Цепочка (порядок в окне) | движение гараж → коридор за 30 с |
| 6 | Трасса по графу зон | дым A → B → C: путь, направление, скорость |
| 7 | Агрегация | N срабатываний за 10 мин; мин/макс/среднее по зоне |
| 8 | Действие / команда | опросить датчики зоны сейчас; интервал 1 с на 5 мин (ID + TTL, откат сам); установить выход: вкл/выкл, импульс зуммера (AD-29); простое «своё событие → свой выход» исполняет сам коллектор |
| 9 | Режим / расписание | «уехал»/«дома»/«ночь» включает наборы правил |

Условие `when` (необязательно), проверяется при сохранении:

```
when: (ch("гараж/дверь").state == open and ch("гараж/t").value < 5)
      and mode != "дома" and time in 22:00..07:00
```

- Операторы: `and`, `or`, `not`, скобки, `== != < <= > >=`.
- Операнды: `ch("зона/имя").value | state | health`, `mode`, `time in ЧЧ:ММ..ЧЧ:ММ`, `day in mon..fri`, числа, строки.
- Ограничения: ≤ 256 символов, ≤ 8 уровней вложенности; без переменных, функций и циклов. Незнакомый шаблон (узел N−1) не исполняется и помечается в вебе.
